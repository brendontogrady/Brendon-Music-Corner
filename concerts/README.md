# Brendon Music Corner · Concert Archive prototype

Open `index.html` in a browser. The page has seventeen events (sixteen shows and one festival), forty-three compressed clips, posters, venue/artist filtering, and listening counts drawn from the attached Apple Music spreadsheet. The original phone uploads are not included; the packaged copies are smaller web versions.

The show listing on Concert Archives confirms Outta Pocket, Fools Game, Invoke, Deprave, and Terminal at Cinco de Mayo on February 4, 2026: https://www.concertarchives.org/bands/fools-game . The user's memory identifies Outta Pocket and Fools Game as headliners. The file timestamps place all three clips that evening. Clips are grouped with the show lineup without claiming they depict a particular band. An optional band field can be added to any clip when Brendon identifies it.

To merge this into the earlier Brendon Music Corner site, add this folder as a `/concerts/` route and a navigation link to it. Artist cards can be wired to that site's exact artist route once its files are available. Keep `concerts.json` as the source for further shows; each media item can later point to a YouTube video ID or another video host instead of a local MP4. Avoid uploading the original 400 MB of phone videos to a GitHub repository.
